# SQL & Power BI Analytics Portfolio

Intermediate-level portfolio demonstrating SQL querying, data modelling, KPI design and Power BI dashboard development.

## Projects
- [Retail Sales & Customer Analysis](SQL-Projects/Retail-Sales-Customer-Analysis/README.md) — PostgreSQL, joins, CTEs, window functions and customer analysis.
- [Sales Performance Dashboard](PowerBI-Projects/Sales-Performance-Dashboard/README.md) — Power BI, DAX, Power Query and executive reporting.

All datasets are synthetic and use INR. Review each project README for setup and validation steps.

The repository includes Power BI source materials (CSV, DAX, M and report specification). Generate and save the native PBIX using Power BI Desktop; no binary PBIX is claimed as included.
